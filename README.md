# AquaResearch

**An Open-Source Research Hub for Underwater Image Enhancement**

## About

AquaResearch is a collaborative open-source project dedicated to organizing and exploring research in Underwater Image Enhancement (UIE).

Our goal is to make research papers, official code repositories, datasets, pretrained models, and evaluation metrics easier to discover and compare.

## Project Goals

* Collect and organize UIE research papers.
* Link papers to their official code repositories.
* Document publicly available datasets and pretrained weights.
* Record evaluation metrics and benchmark protocols.
* Test selected methods and, in the future, explore a unified framework for underwater image enhancement.

## Research Categories

* Traditional image enhancement
* CNN-based methods
* GAN-based methods
* Transformer-based methods
* Diffusion-based methods
* Unsupervised and zero-reference methods

## Datasets

We plan to document datasets such as UIEB, EUVP, LSUI, and RUIE, including their official sources and usage terms.

## Contributing

Researchers, students, and developers are welcome to contribute by adding papers, verifying repository links, documenting datasets, and testing methods.

Please verify the original paper, official code, license, and availability of pretrained weights before submitting a method.
